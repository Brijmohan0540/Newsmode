# NewsHub

A modern news and blog dashboard prototype built with plain HTML, CSS, and JavaScript.

## Features

- Trending news section
- Latest stories grid
- Search with live suggestions
- Category filtering
- Responsive layout
- Post detail view
- Login/Register modals
- Admin panel for managing posts, users, contacts, and settings
- Dynamic sidebar widget and ticker updates
- In-browser data storage simulation

## Files

- `newshub.html` — main page with all markup, styles, and scripts

## Usage

1. Open `newshub.html` in a browser.
2. Use the interface to browse posts, search, filter by category, and manage content.


## Notes

- This is a static demo with in-memory data, no backend persistence.
- Customize content and settings directly in `newshub.html` as needed.
